# 千川共享盘上传助手

Windows 10/11 桌面上传客户端，不需要 GPT 或 Python。使用已安装的 Microsoft Edge，每台电脑由使用者自行登录千川。源代码和安装包仅在本私有仓库分享。

## 安装

1. 从本仓库 **Releases** 下载 `QianchuanAgent-Windows-x64.zip`，完整解压。
2. 双击 `安装.cmd`，安装到当前用户目录并创建桌面快捷方式，无需管理员权限。
3. 打开“千川共享盘上传助手”，填写共享盘总目录、账户文件夹、千川ID和完整账户名。所有电脑必须选择同一个共享盘总目录。
4. 原有上传程序必须先停用。已有历史记录的账户必须先点“导入旧记录”，选择旧版的账户配置和数据库所在文件夹。
5. 选中主户保护的账户保持每日699条自动额度，额外条数逐条人工批准。
6. 点击“开始/继续”，在专用Edge窗口自行登录正确的千川账户。客户端不会保存密码到共享盘。

可以保存多个账户配置，并逐个启动；每个账户使用独立的本机浏览器配置。关闭主窗口会最小化；停止上传请使用“停止全部”。本版本不默认设置开机自启。

## 共享盘多电脑协作

- 同一账户同一时刻只有一个客户端持有Windows/SMB独占文件句柄，其他电脑等待。不同账户可以由不同电脑并行处理。
- 锁不会因“时间过长”而被抢占；共享盘断线时停止提交和删除。
- 文件按SHA-256内容去重；在点击上传前持久化待核对记录。
- 连接中断、登录失效或程序退出后，结果未知的文件只核对素材ID，**不自动重传**。未找到素材ID时停留在待核对状态，须管理员核对平台后处理，不应直接删除记录。
- 账户身份、主户保护设置和每日保守计数保存在共享盘；客户端配置不能静默降低已有主户保护。
- `.qianchuan-agent` 是共享控制目录，不要手工删除或修改。

## 删除规则（包含主户）

只有在正确账户的视频库中查到唯一上传名称和素材ID、成功凭据写入共享盘后，才删除对应原片。删除前独占打开源文件并再次校验内容；变化、被占用或连接异常时保留原片。上传完成/进度100%不是删除依据。

SMB删除通常不经过Windows回收站，请由共享盘管理员配置备份/快照。新版立即清理规则包含主户，与旧版“主户保留、其他午夜清理”不同。

## 限制和验证范围

本版本优先保证去重、账户互斥和删除条件，采用逐条上传；不承诺每小时200～300条。同一宽带上的多电脑不会增加总上行带宽。

当前自动化依赖千川网页上的中文控件；页面变化、验证或登录到期会要求处理。没有使用/承诺官方上传API。主户数量按页面记录和共享保守计数中较大者执行；请避免与未接入本程序的独立上传工具同时操作主户。

发布前运行了进程互斥、凭据持久化、变更文件保留、入库后删除、历史记录导入等自动测试。实际千川登录、公司网络和第二台电脑的完整上传仍需现场验收，不能把单机测试当作多机生产验收。

仓库不含任何公司账户ID、源视频、实际共享盘地址、浏览器登录状态、历史数据库或日志。私有仓库的下载链接需要GitHub账号具有仓库访问权限；同事没有权限时，可由管理员把安装ZIP放在公司共享盘分发。

## 本地构建

使用Python 3.12（64位）：

```powershell
python -m pip install -r requirements-build.txt
python -m pytest -q
python -m PyInstaller --noconfirm --clean --windowed --name QianchuanAgent --collect-all playwright app.py
```

把 `dist/QianchuanAgent` 文件夹与 `安装.cmd`、`install.ps1` 和本说明一同打包。发布工作流仅在手动触发或推送版本标签后生成GitHub Release。
